Detailed Description

Beheert alle kamers en vergaderingen in het systeem.

  • Dit is de centrale klasse (het hart van het domein) die verantwoordelijk is voor het opslaan van de data en het verwerken van de simulatie om dubbele boekingen te voorkomen.
