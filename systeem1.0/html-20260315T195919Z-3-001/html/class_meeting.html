Detailed Description

Vertegenwoordigt een ingeplande vergadering.

  • Slaat de gegevens op van een vergadering, inclusief de deelnemers, de toegewezen kamer, en houdt bij of de vergadering succesvol is verwerkt of geannuleerd.
